# Smartphone Market Analysis Project

A Python data analysis application developed to evaluate smartphone sales performance, customer satisfaction, and brand positioning.

## 📊 Key Analysis Areas Include:
* **Sales Performance & Revenue Analysis** – Tracking which models bring in the most volume and revenue.
* **Feature Comparisons** – Evaluating key device metrics like Camera, Battery capacity, Storage, and RAM.
* **Price Analysis & Market Positioning** – Mapping out high-end flagship devices versus budget options.
* **Customer Rating & Warranty Analysis** – Reviewing user satisfaction metrics against brand warranty offerings.

## 🛠️ Tech Stack & Dependencies
* **Python 3** – Core programming logic and terminal interface.
* **Pandas** – Data manipulation, cleaning, and structured CSV parsing.
* **Matplotlib** – Data visualization and metric plotting.
